# Cloudflare Edge

This directory manages Cloudflare DNS and zone settings separately from the
NixOS configuration. The wildcard record and `always_use_https` setting live in
`dns.tf`; Cloudflare Tunnel ingress remains generated by
`modules/nixos/homelab/cloudflared.nix`.

Use the repository dev shell, initialize only when needed, and inspect a plan
before applying:

```sh
nix develop
tofu init
tofu plan
tofu apply
```

Supply the API token through a secret-safe mechanism described in the local
README. Do not print it, commit it, put it in Terraform configuration, or use
shell command substitution to decrypt it. Keep the domain, zone, and tunnel
identifiers synchronized with
`configurations/nixos/homestation/default.nix` when either side intentionally
changes.

If adopting an existing Cloudflare object, import it first and require a
no-change plan before applying. Do not mix an OpenTofu state change with an
unrelated NixOS activation.
